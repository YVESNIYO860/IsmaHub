# ISMAHUB LTD Technology Store Management System

A modern React + TypeScript front-end for a premium technology retail operating experience. The interface includes:

- A polished admin dashboard for sales, inventory, and delivery visibility
- Product catalog management views for stock and availability tracking
- Order operations and delivery status views
- A responsive footer and navigation tailored to ISMAHUB LTD

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

This version is a production-ready front-end foundation designed for future integration with Supabase, authentication, maps, and reporting workflows.
